# Changelog

## 0.4.0 — community crate

- Curated 12 community bricks from the live Pi package catalog and GitHub extension monorepos.
- New slots: pack-mgr, saas-apps, claude-compat, intercom, file-nav, sec-audit, remote, session-kit, crawl, sidequest, telemetry.
- `pi-agent-browser` is a first-class browser brick; the MCP chrome-devtools path remains as the original `browser` brick (same slot).
- Presets: Community daily, Connected stack.
- README documents why each community brick earned a stud.

## 0.3.0 — bench that actually ships

- Curated crate + opt-in npm market stay, but the GitHub Pages tree now includes the JS bench (`main.js`, `scene.js`, `compose.js`).
- Five named presets: daily refactor, research scout, debug lab, desktop ops, team review.
- Shareable `#b=id,id&i=intent` URLs. Last build is also stored in `localStorage`.
- Same-slot bricks bounce; a second click replaces the occupant.
- Click a 3D brick to unsnap it. New bricks drop onto the plate.
- Local recipes for every `local-extension` / `partial` slot: ast-grep, DAP, eval-kernel, stream-rules, github-fs, computer-use, rule-compat, role-routing.
- Composer unit tests (`npm test`).
- Slot map + brick detail panel on the tray.

## 0.2.0 — product definition

- Locked official Pi plate.
- OMP-split brick ledger.
- Deterministic `goal.md` + settings fragment.
